# SafetyClip releases

Downloads and update feeds for [SafetyClip](https://www.appmacha.com/safetyclip), a clipboard manager for Mac that keeps your secrets out of other apps.

This repository only holds signed, notarized builds. SafetyClip needs a license key to run: get one at [appmacha.com/safetyclip](https://www.appmacha.com/safetyclip). The source code comes with every license.

- **Download the latest version:** [SafetyClip.dmg](https://github.com/appmacha/safetyclip-releases/releases/latest/download/SafetyClip.dmg)
- **Help:** support@appmacha.com
